## System Libraries Installed
| Package Name | Description | Key Features / Contains |
| :--- | :--- | :--- |
| **git** | A distributed version control system for tracking changes in source code during software development. | `git`, `git-clone`, `git-pull`, `git-push`, `git-commit`. The core tool for collaboration and code management. |
| **curl** | A command-line tool and library for transferring data with URLs. Supports a vast number of protocols. | **Protocols:** HTTP, HTTPS, FTP, SFTP, SCP, and more. Used for API interaction, downloading files, and testing web services. |
